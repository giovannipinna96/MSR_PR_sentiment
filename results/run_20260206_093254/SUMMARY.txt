----------------------------------------------------------------------
METHODOLOGICAL NOTES:
----------------------------------------------------------------------

1. Human Baseline Exclusion:
   The AIDev dataset does not include review comments for Human PRs.
   Human data is excluded from statistical tests due to insufficient
   sample size (< 100 samples). Human data is retained for descriptive
   statistics only.

2. Category Friction Scores:
   Category friction statistics (Testing, Security, Code Style, etc.)
   are calculated ONLY on negative comments. This is by design:
   - Friction categories are assigned only to negative comments
   - Mean friction scores for categories (0.6-0.7) are higher than
     per-agent means (0.1-0.3) because they exclude neutral/positive
   - Per-agent means include all comments regardless of sentiment

3. Multi-Model Validation:
   All sentiment models use 3-class output (negative/neutral/positive)
   to ensure valid Cohen's Kappa inter-model agreement calculation.
